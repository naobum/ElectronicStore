# ElectronicStore - Фронтенд

Полнофункциональное React приложение для электронного магазина с тремя основными страницами.

## 📋 Структура проекта

```
client/src/
├── pages/              # Основные страницы приложения
│   ├── Products.jsx   # Страница товаров с фильтрами
│   ├── Cart.jsx       # Страница корзины
│   └── Admin.jsx      # Админ-панель
├── components/         # Переиспользуемые компоненты
│   ├── ProductCard.jsx
│   ├── SearchFilters.jsx
│   ├── ProductForm.jsx
│   └── BrandForm.jsx
├── context/           # React Context для управления состоянием
│   └── CartContext.jsx
├── services/          # API сервисы
│   └── api.js
├── styles/            # CSS файлы
│   ├── Products.css
│   ├── Cart.css
│   ├── Admin.css
│   ├── ProductCard.css
│   ├── SearchFilters.css
│   ├── ProductForm.css
│   └── BrandForm.css
├── App.jsx
└── main.jsx
```

## 🚀 Функциональность

### 1. Страница Товаров (`/pages/Products.jsx`)
- Вывод всех товаров в виде сетки
- **Фильтры поиска:**
  - Поиск по названию товара
  - Фильтрация по бренду
  - Фильтрация по рейтингу (минимальный рейтинг)
- Отображение информации: название, бренд, рейтинг, описание, количество отзывов
- Кнопка "В корзину" для добавления товара

### 2. Страница Корзины (`/pages/Cart.jsx`)
- Список всех товаров в корзине
- Управление количеством товаров (+/-)
- Удаление товаров из корзины
- Расчёт итоговой стоимости
- Кнопка "Оформить заказ"
- Кнопка "Очистить корзину"

### 3. Админ-панель (`/pages/Admin.jsx`)
Четыре вкладки управления:

#### Товары
- Список всех товаров в таблице
- Форма для добавления новых товаров
- Редактирование товаров
- Удаление товаров

#### Бренды
- Список всех брендов
- Форма для добавления новых брендов
- Редактирование брендов
- Удаление брендов

#### Пользователи
- Список всех пользователей
- Удаление пользователей

#### Отзывы
- Список всех отзывов
- Удаление отзывов

## 🔧 API Интеграция

API сервис расположен в `src/services/api.js` и содержит функции для:

- **Products**: `getAll()`, `getById()`, `create()`, `update()`, `delete()`
- **Brands**: `getAll()`, `getById()`, `create()`, `update()`, `delete()`
- **Cart**: `getAll()`, `getById()`, `create()`, `update()`, `delete()`
- **Users**: `getAll()`, `getById()`, `create()`, `update()`, `delete()`
- **Reviews**: `getAll()`, `create()`, `delete()`

### Конфигурация API

По умолчанию API подключается к `http://localhost:5190/api`

Для изменения адреса API отредактируйте `src/services/api.js`:

```javascript
const API_BASE_URL = 'http://localhost:5190/api'; // Измените на ваш адрес
```

## 🗂️ State Management

### CartContext (`src/context/CartContext.jsx`)

Глобальное управление корзиной с функциями:
- `addToCart(product)` - добавить товар в корзину
- `removeFromCart(productId)` - удалить товар
- `updateQuantity(productId, quantity)` - изменить количество
- `clearCart()` - очистить корзину
- `getTotalPrice()` - получить итоговую стоимость

Использование:
```jsx
import { useCart } from './context/CartContext';

function MyComponent() {
  const { cartItems, addToCart, removeFromCart } = useCart();
  // ...
}
```

## 🎨 Стили

Приложение использует модульный CSS подход. Все стили сгруппированы по компонентам в папке `src/styles/`.

Основные цвета:
- Зелёный (основной): `#4CAF50`
- Серый: `#666`, `#999`
- Белый: `#fff`, `#f5f5f5`

## 📦 Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение в режиме разработки:
```bash
npm run dev
```

3. Откройте в браузере: `http://localhost:5173`

## 🏗️ Построение для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## 🔍 Примечания

- Приложение использует React 19.2.5 и Vite
- Состояние корзины хранится в памяти (потеряется при перезагрузке страницы)
- API URL зависит от конфигурации вашего бэкенда
- Для полной функциональности убедитесь, что бэкенд запущен и доступен
